# Practical 04 — From Notebook to Package

SCSE3040 Machine Learning Operations

## Module responsibilities

- `delivery/__init__.py` — Exposes the package's public API and version.
- `delivery/data.py` — Loads the delivery dataset and creates the train/test split.
- `delivery/features.py` — Provides delivery-order descriptions and speed calculations.
- `delivery/model.py` — Trains, evaluates, saves, and loads the delivery-time model.
- `delivery/validate.py` — Validates delivery orders against the four required input rules.
- `train.py` — Trains the model from the command line and saves it.
- `predict.py` — Loads the saved model and predicts the time for one delivery order.
